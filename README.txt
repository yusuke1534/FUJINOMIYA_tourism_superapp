FUJINOMIYA 富士宮まるごと観光｜初期版

画像・配色・カード・メニューはご指定のデザイン画像をもとに再現しました。
ホーム以外に、カテゴリ検索、横断検索、絞り込み、スポット詳細、お気に入りの端末保存、地図、外部ルート案内、簡易観光トークが入っています。

公開方法（iPhoneのみでも可能）
1. GitHub のリポジトリを Safari で開きます。
2. index.html / style.css / app.js / sw.js / manifest.webmanifest と assets フォルダ内の画像ファイルを、同じ構成でアップロードします。
3. Settings → Pages で main ブランチのルートを指定すると、公開URLで動作します。
4. iPhone Safari で公開URLを開き、「共有」→「ホーム画面に追加」から起動アイコンを作成できます。
※すでにGitHub Pagesを公開している場合は、公開元ブランチなど既存設定をむやみに変更しないでください。

単独の index.html を使う場合は、ZIP内のファイルではなく、別途お渡しした「1ファイル版 index.html」を使います。
それだけをリポジトリ直下へアップロードすると、画像も含めて表示されます。PWA向けの追加ファイルはZIP版に同梱されています。
